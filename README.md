# GD Menu by 34f

A Geode mod for Geometry Dash 2.2091 on Windows. It targets Geode 6.0.0-alpha.1.

## Install

1. Install a compatible version of [Geode](https://geode-sdk.org/install).
2. Close Geometry Dash and copy `34f.gdmenu.geode` into the game's `geode/mods` folder.
3. Start Geometry Dash. Press **Tab** to open GD Menu.

To upgrade from an older mod ID, move its package out of the game's `geode/mods`
folder. With the game closed, copy the contents of its data folder under
`%LOCALAPPDATA%\GeometryDash\geode\mods` into `34f.gdmenu` in that directory.
Keep the original as a backup.

See [build instructions](AGENTS.md) and [replay controls](docs/replay.md).
